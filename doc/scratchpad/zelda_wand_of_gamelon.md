By hardware fuzzing, the puzzle has been solved.

Back then I thought that AUDCTL = 0 would stop the playback instantly. That was actually partially right.
If the internal ACHAN of the DSP behind the CDIC is set to 0, then the playback will continue until the current buffer has been decoded.
If the internal ACHAN of the DSP is not 0, then the playback will stop either at a soundgroup level or instantly.
The internal ACHAN is updated via 0x2E command that of course also needs to be executed by applying bit 15 of DBUF. 

This means, I need a mix of the Chaos Control fix and the state before that.
